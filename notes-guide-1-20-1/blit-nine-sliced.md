# Nine-Slice Rendering — Minecraft 1.20.1

## Что это

Nine-Slice (9-Slice) позволяет создавать GUI-элементы переменного размера на основе небольшой исходной текстуры.

Текстура условно разделяется на 9 частей:

```text
┌─────┬─────┬─────┐
│  1  │  2  │  3  │
├─────┼─────┼─────┤
│  4  │  5  │  6  │
├─────┼─────┼─────┤
│  7  │  8  │  9  │
└─────┴─────┴─────┘
```

* `1, 3, 7, 9` — углы, которые сохраняют свой размер.
* `2, 8` — верхняя и нижняя границы.
* `4, 6` — левая и правая границы.
* `5` — центральная область.

При изменении размера GUI углы не растягиваются, поэтому они не искажаются.

## Метод Minecraft

В Minecraft 1.20.1 для этого используется:

```java
graphics.blitNineSliced(...)
```

У `GuiGraphics` есть несколько перегрузок этого метода.

### Простая перегрузка

Например:

```java
graphics.blitNineSliced(
    TEXTURE,
    x,
    y,
    width,
    height,
    sliceWidth,
    sliceHeight,
    textureWidth,
    textureHeight,
    u,
    v
);
```

Основные параметры:

* `TEXTURE` — исходная текстура.
* `x` — X-позиция GUI на экране.
* `y` — Y-позиция GUI на экране.
* `width` — итоговая ширина GUI.
* `height` — итоговая высота GUI.
* `sliceWidth` — ширина левого и правого среза.
* `sliceHeight` — высота верхнего и нижнего среза.
* `textureWidth` — ширина исходной текстуры.
* `textureHeight` — высота исходной текстуры.
* `u` — X-координата области внутри текстуры.
* `v` — Y-координата области внутри текстуры.

Например, для текстуры `17×17` с углами `5 px`:

```java
graphics.blitNineSliced(
    TEXTURE,
    x,
    y,
    140,
    220,
    5,
    5,
    17,
    17,
    0,
    0
);
```
