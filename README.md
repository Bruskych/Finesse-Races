### Finesse Races 🐉
Finesse Races — модификация для Minecraft (на момент создания репозитория — версия 1.20.1 Forge), разрабатываемая в рамках бакалаврской работы, а также специально для авторского модпака под названием Idyllia. Проект представляет собой не только игровой мод, но и подробное практическое руководство по созданию модификаций с нуля.

### 📌 О проекте
Данный проект — первая работа автора в сфере разработки модификаций для Minecraft. Главная особенность репозитория заключается в том, что помимо самого исходного кода, здесь подробно и пошагово документируется весь процесс разработки:

* Начальные шаги и настройка окружения;
* Используемые источники, документация и инструменты;
* Возникавшие проблемы, ошибки и способы их решения;
* Архитектурные решения и структура кода.

Этот репозиторий может служить ```наглядным практическим руководством``` для разработчиков-новичков. Если у вас нет собственного опыта в создании модов, вы можете опираться на задокументированный путь автора. Все руководства и материалы представлены на русском языке.

### 🎭 Игровая концепция
Основная идея модификации — добавление системы рас (расовых классов). Каждая раса обладает уникальными преимуществами и недостатками, что позволяет:

* Разнообразить привычный игровой процесс;
* Частично усложнить прохождение игры;
* Внести новые механики взаимодействия в многопользовательском режиме (кооперативе и PvP), стимулируя командную работу игроков разных рас.

### Finesse Races 🐉
Finesse Races is a Minecraft modification (version 1.20.1 Forge at the time of repository creation) developed as part of a Bachelor's thesis project, as well as specifically for the author's custom modpack named Idyllia. This repository contains both the mod itself and a detailed step-by-step guide to modding from scratch.

### 📌 About The Project
This is the author's debut project in the Minecraft modding field. The key highlight of this repository is its comprehensive documentation covering every stage of the development lifecycle:

* Initial setup and environment configuration;
* Utilized resources, documentation, and tooling;
* Encountered bugs, challenges, and their solutions;
* Architectural decisions and code organization.

This repository serves as a ```practical reference guide``` for aspiring mod creators. Developers without prior experience can rely on the documented workflow. Please note that the detailed guides and technical documentation are provided in Russian.

### 🎭 Core Gameplay Features
The main focus of the mod is the introduction of a playable Race system. Each race comes with its own unique traits and drawbacks, designed to:

* Refresh traditional Minecraft gameplay;
* Increase difficulty through balanced trade-offs;
* Enhance multiplayer dynamics by encouraging cooperative and tactical interactions between different species.
