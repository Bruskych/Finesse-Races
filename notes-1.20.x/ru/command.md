# Команды (чат)

## Типы прав доступа (.hasPermission(?))

- Уровень 0 (Обычный игрок): Нет прав администратора. Игрок может использовать только базовые команды, не влияющие на других (например, /help, /me, /trigger, /msg).
- Уровень 1 (Модератор): Позволяет обходить защиту спавна (spawn protection) на сервере. Команд с этим уровнем почти нет.
- Уровень 2 (Гейммастер/Читы): Стандартный уровень "оператора" для изменения игрового процесса. Дает доступ к командам командных блоков и читам: /gamemode, /give, /tp, /time, /weather, /setblock. Именно поэтому для твоего мода мы использовали 2.
- Уровень 3 (Администратор): Управление игроками на сервере. Дает доступ к командам модерации: /ban, /kick, /op, /deop.
- Уровень 4 (Владелец/Консоль): Полное управление сервером. Дает доступ к командам, влияющим на работу самого сервера: /stop, /save-all, /save-on.
