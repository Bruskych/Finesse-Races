## S004

- Дата доступа: 20.09.2026
- Название: GuiGraphics — Minecraft 1.20.1 Mappings
- Автор: Minecraft community mappings
- Ссылка: https://mappings.dev/1.20.1/net/minecraft/client/gui/GuiGraphics.html
- Платформа: Mappings.dev
- Дата публикации: Не указана

### Что изучено

- Изучен принцип работы Nine-Slice Rendering и разделение текстуры на девять частей.
- Изучено устройство метода `blitNineSliced(...)` класса `GuiGraphics`.
- Изучено отличие растягивания центральной области от её повторения.

### Где использовано

- Реализованный метод `renderNineSlice(...)` добавлен в библиотеку `Remedy Core` в класс `GuiRenderHelper`.
- Метод используется в `RaceSelectionScreen` мода `Finesse Races`.
- С его помощью создаются три масштабируемые панели интерфейса выбора расы.
- Разные участки исходной текстуры используются для левой, центральной и правой панелей.

## S013

- Дата доступа: 24.09.2026
- Название: Class TickEvent (Minecraft Forge 1.20.1 JavaDoc)
- Автор: Команда разработчиков Minecraft Forge
- Ссылка: https://lexxie.dev/forge/1.20.1/net/minecraftforge/event/TickEvent
- Платформа: Lexxie Dev (Документация)
- Дата публикации: Не указана

### Что изучено
- Изучена концепция игровых тиков (базовых циклов обновления игры) и архитектура события TickEvent в библиотеке Forge.
- Рассмотрены различные подклассы тиков (клиентские, серверные, мировые и тики сущностей), а также жизненный цикл события, разделенный на фазы START и END.
- Освоены принципы безопасной подписки на глобальную шину событий для выполнения периодического кода без создания чрезмерной нагрузки на сервер.

### Где использовано
- Полученные знания применены при разработке системы рас (класс PlayerEvents). На основе события TickEvent.PlayerTickEvent реализован обработчик, который в реальном времени отслеживает состояния игрока и принадлежность к расе, чтобы динамически накладывать на него уникальные эффекты, бонусы или ограничения (например, проверку нахождения в воде).

- Дата публикации: Не указана
